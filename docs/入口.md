## 基础积累

### 两种坐标轴定义
世界坐标（World）：场景全局固定坐标轴，X→右、Y→上、Z→前（Unity 标准），永远不变。
本地坐标（Local）：依附物体自身，跟随物体、父物体一起旋转，，旋转后，本地坐标轴的朝向变了，但是切换到世界坐标中，朝向固定变为世界轴朝向

### 速度方向
如：`rb.setLinearVelocity(new Vec3(0, 0, -200)); // ✅ 正确API，沿着自身前方（transform.forward）往 Z 负方向冲（默认z正方向是朝向屏幕外的）`

#### 一、物理移动（有物理碰撞、受力）
前提：必须挂载对应刚体组件
RigidBody2D（2D）
Dynamic：✅ 可用 linearVelocity 设置线性速度，受重力、摩擦力、碰撞影响
Kinematic：❌ 不能用速度，使用 movePosition()
Static：❌ 完全不可动
RigidBody（3D）
Dynamic：✅ setLinearVelocity(Vec3)
Kinematic：❌ 不能用速度，movePosition()
关键：速度 API 只对动态刚体 Dynamic生效
#### 二、非物理移动（无物理、不受力，节点平移）
不需要刚体！纯粹修改节点坐标
node.setPosition () /node.position 瞬时瞬移
node.translate () 持续平移
tween 缓动移动
特点：不会触发物理碰撞、不受重力、无摩擦力
#### 三、关键区分
设置线性速度 = 物理引擎驱动移动 → 依赖 Dynamic 刚体
translate / 直接改坐标 = Transform 逻辑移动 → 不需要刚体
不要混用：update 持续给刚体赋值 linearVelocity，会抵消重力、摩擦力
#### 四、快速选型口诀
需要碰撞、弹跳、重力 → 动态刚体 + linearVelocity
需要移动但不想受物理规则影响 → translate / Tween
平台角色、子弹、掉落物 → 刚体速度
UI、背景、装饰平滑滑动 → Tween/translate
#### 五、高频坑
Kinematic 刚体禁止使用速度 API
3D RigidBody 不能直接 .linearVelocity=，必须 setLinearVelocity()
Vec2 只有 xy；3D 移动使用 Vec3

# Cocos Creator 2D 节点常用分类属性（结合你当前项目新手坑总结）
把节点属性分成 **基础变换、渲染控制、交互开关、分层相机、UI专用、事件相关** 六大类，附带作用、新手易错点。

## 一、基础变换属性（所有节点通用）
1. **Position（坐标）**
    - `node.position`：**本地坐标**，相对于父节点
    - `node.worldPosition`：世界坐标（全局画布坐标）
    ⚠️坑：方块和玩家父节点不一致，直接用position对比，坐标错位。
2. **Rotation（旋转）**
    2D一般只用Z轴旋转。
3. **Scale（缩放）**
    缩放会连带影响子节点大小。
4. **Anchor（锚点）**
    图形旋转、位移的基准中心点。
    ⚠️坑：Sprite锚点不是中心，跳跃对齐格子时发生视觉偏移。
5. **active（激活开关）**
    `node.active = true/false`
    false：节点及其所有子节点**不渲染、不接收事件、脚本不执行start/update**。
    你菜单 StartMenu 显隐就是靠这个属性。

## 二、渲染可见相关属性
1. **Layer（图层标签）【重点】**
    内置常用：`DEFAULT` / `UI_2D`
    作用：给物体打分类标签，配合相机 `Visibility` 筛选渲染。
    ❌误区：Layer不能直接控制遮挡，仅作为相机筛选标记。

2. **Opacity（透明度 0~255）**
    0完全透明、255不透明；透明物体依然参与渲染、可以接收点击。

3. **Color（颜色）**
    Sprite/Label染色，白色原图不改变色相。

## 三、UITransform（UI节点必备组件，所有UI元素自动挂载）
> 只有带有UITransform的节点，才能正常做界面布局
1. **Content Size**：矩形尺寸（宽高）
2. **Anchor Point**：锚点（和节点Anchor是同一个东西）
3. **Priority（渲染优先级）**
    同Layer下，优先级数字越大，渲染越靠上层；
    ✅适用：弹窗置顶；常规UI优先使用**节点树顺序**，少用Priority。

## 四、Sprite 组件属性（图片节点 Bg/方块）
1. **Sprite Frame**：图片资源
2. **Type（渲染模式）**
    - `SIMPLE`：整体拉伸
    - `SLICED`：九宫格（弹窗背景专用，保护边角不变形）
    - `TILED`：平铺重复
    - `FILLED`：单向填充（进度条）
3. **Size Mode**
    CUSTOM：使用UITransform尺寸；RAW：使用图片原始尺寸。

## 五、Label 文字组件
1. **String**：文本内容
2. **Font**：字体资源
3. **Horizontal/Vertical Align**：文字对齐方式

## 六、Button 按钮交互组件
1. **Target**：接收点击事件的节点
2. **Interactable**：是否可点击；false时按钮变灰、无法触发回调
⚠️坑：被Bg遮挡的按钮，就算Interactable=true，也接收不到点击。

## 七、相机 Camera 关键属性（卷轴分层核心）
1. **Visibility（可见掩码）**
    相机只渲染勾选Layer上的物体；分层方案最核心配置。
2. **Projection（投影模式）**
    2D游戏固定选择 **Orthographic（正交投影）**
3. **Orthographic Size**：可视范围大小
4. **Clear Flags**：画面背景填充方式

## 八、Canvas 画布组件（全局UI根节点）
1. **Align Canvas With Screen**
    ⚠️卷轴必备：关闭！解除画布锁定，相机跟随移动才能正常滚动场景。
2. **Design Resolution**：设计分辨率（美术画布尺寸）

## 九、事件、输入相关属性
1. **node.on() / node.off()**：节点自定义事件监听
    ```ts
    this.playerCtrl.node.on('JumpEnd', this.onPlayerJumpEnd, this);
    ```
2. **Input事件监听**：鼠标、触摸输入
⚠️坑：游戏刚启动立刻开启输入，容易误触；使用setTimeout延迟激活。

## 十、父子节点核心规则（重中之重）
1. 父节点 active=false → 所有子节点强制失效；
2. 子节点 Position = **相对父节点本地坐标**；
3. 渲染顺序：**层级管理器从上至下绘制，下方节点覆盖上方节点**；
4. 子节点跟随父节点位移、缩放、旋转（相机挂Player实现跟随的原理）。
